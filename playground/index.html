系統架構與開發導覽 (Playground)

本頁面詳述了雪坊銷售數據分析系統的內部運作機制，作為開發者調試與理解架構之用。

1. 核心設計理念

本系統採用 **輕量化單頁應用 (SPA)** 的思維，不依賴龐大的框架（如 React/Vue），而是使用 Vanilla JS 以獲得最高的載入速度與 GitHub Pages 相容性。

2. 資料流動流程

1. 數據獲取
rawData Array
➔
2. 篩選與計算
Array.filter / Map
➔
3. 圖表渲染
Chart.js API
➔
4. UI 更新
DOM Manipulation

3. 技術規格

  • 繪圖引擎： Chart.js v3+
  • 互動導覽： Intro.js
  • AI 分析： Google Gemini API (REST)
  • 樣式控制： CSS Custom Properties (Variables)

4. 開發工具與輔助腳本 (Scripts)

除了前端展現層，本專案還包含以下位於根目錄的腳本，用於數據的預處理與離線分析：

  • analyze_fnb.py (Python/Pandas)：
    功能：數據清洗專家。負責處理 CSV 中的缺失值、移除重複紀錄，並進行精確的統計聚合運算。
  • analyze_fnb.ps1 (PowerShell)：
    功能：快速分析工具。在終端機直接產出「熱銷 Top 5」與「滯銷 Bottom 5」的品項對比報告。
  • analyze_fnb_v2.ps1 (PowerShell V2)：
    功能：增強型處理。支援欄位映射與格式轉換，將原始 CSV 轉化為更易讀的結構化數據。
